# Fatih Demirtas — Portfolio

Persönliches Portfolio-Website von Fatih Demirtas, Data & BI Analyst aus Bamberg.

Live: [https://demirtas-fatih.github.io/demirtas-fatih/](https://demirtas-fatih.github.io/demirtas-fatih/)

## Über das Projekt

Statische Portfolio-Website mit mehrsprachiger Unterstützung (Deutsch / Englisch). Gebaut mit HTML, CSS, Bootstrap und Vanilla JavaScript.

## Funktionen

- Zweisprachige Benutzeroberfläche (DE / EN)
- Projektgalerie mit interaktivem Lightbox
- Kenntnisse & Tools Übersicht
- Lebenslauf-Sektion mit Berufserfahrung & Zertifikaten
- Kontaktbereich
- Responsives Design (Mobile-First)

## Tech Stack

- HTML5 / CSS3
- Bootstrap 4
- JavaScript (Vanilla)
- AOS (Animate on Scroll)
- GLightbox
- GitHub Pages (Hosting)

## Projekte

- Microsoft 365 Copilot Agents
- Email Reminder Flow – Power Automate
- Financial Reporting Pipeline (Python)
- E-Commerce SQL Analysis (Python + SQL)
- Weather ETL Pipeline (Python + Streamlit)
- Av. Elif Eren – Law Office Website
- Bambados – QR Code Menu
